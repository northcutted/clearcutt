# 🚀 ClearCutt Hardened Fleet Release v0.11.1

This release has been **cryptographically certified** with **no fixable Critical/High CVEs in gated production tiers at release time** and **SLSA Level 3 non-falsifiable provenance** across our multi-architecture fleet (supporting both `amd64` and `arm64` natively).

All OCI layered manifests have been keylessly signed via Sigstore OIDC, and full SPDX SBOM audits are attached as release assets.

## ❄️ Declarative Nix Flake Integration
Downstream development projects can consume these exact secure runtime runtimes natively in their Nix flakes:

```nix
# Add this repository to your flake inputs:
inputs.clearcutt.url = "github:northcutted/clearcutt/v0.11.1";

# In your outputs, use the overlays or raw runtime packages:
outputs = { self, nixpkgs, clearcutt, ... }: {
  devShells.x86_64-linux.default = nixpkgs.legacyPackages.x86_64-linux.mkShell {
    buildInputs = [
      # Access secure, identical overlays
      clearcutt.packages.x86_64-linux.java21-dev
    ];
  };
};
```
