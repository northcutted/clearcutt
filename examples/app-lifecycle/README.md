# ClearCutt App Lifecycle Examples

The canonical, maintained examples for every supported ClearCutt stack live in
[`docs/app-lifecycle.md`](../../docs/app-lifecycle.md).

That guide covers:

- Core/static utility images on `coreLTS-*`,
- Java 21 and 25,
- Node.js 22 and 24,
- Python 3.14,
- Go 1.25 and 1.26,
- .NET 8 and 10,
- Rust 1.95,
- C/C++ 15,
- the common sign, diff, rebase, verify, and admission-gating loop.

Keep stack-specific example projects free to evolve independently, but keep the
end-to-end CLI flow aligned with the guide above.
