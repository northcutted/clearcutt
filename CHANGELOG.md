# Changelog

ClearCutt is pre-1.0: minor releases may include breaking changes, and only
the latest release is supported (see [SECURITY.md](SECURITY.md)).

Full release history — notes, signed CLI binaries, SBOMs, and SLSA provenance
assets — lives on
[GitHub Releases](https://github.com/northcutted/clearcutt/releases).
Release notes are generated by the release workflow
(`clearcutt fleet finalize-release`).
